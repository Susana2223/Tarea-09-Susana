# Fiel Amigo

## Sistema de registro de mascotas

Fiel Amigo es una interfaz web diseñada para mostrar y administrar los registros de mascotas.
Cuenta con una tabla donde se visualizan los datos de cada mascota y opciones para registrar, editar y eliminar.

**Solo es maquetación: no tiene backend, base de datos ni lógica de programación**

## Características

- Barra de navegación en la parte superior.
- Tabla con los datos de las mascotas: nombre, especie, raza, tamaño, sexo, edad y peso.
- Columna **Operaciones** con botones de editar y eliminar.
- Paginación para organizar la lista de mascotas.
- Botón **Registrar mascota** que abre un dialog con el formulario de registro.
- Dialog para editar una mascota y dialog de confirmación para eliminarla.
- Diseño adaptable a computadora, tablet y celular.

## Tecnologías utilizadas

- HTML5
- [Bootstrap 6](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/)

## Requisitos

- Navegador web actualizado: Chrome o Edge 130 o superior.
- Conexión a internet para cargar Bootstrap mediante CDN.

## Ejecución

- Abrir el archivo `index.html` en el navegador para visualizar la interfaz.
